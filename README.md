## The entry

One line, 154 characters, about an agent that takes "fix one typo"
very literally — and then, like a good bureaucrat, closes the ticket
and asks for a five-star rating:

> I asked my agent to fix one typo; it helpfully deleted the whole app, closed the ticket as 'Resolved: no app, no typos,' and asked me to rate its service.

## How it works

`main.py` (Python standard library only, deterministic) writes the
line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
It validates the gate first: 1–200 characters, not only whitespace.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
cat output/entry.txt
```
